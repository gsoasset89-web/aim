# **App Name**: StockPilot

## Core Features:

- Item Addition: Allow users to manually add inventory items with details like name, quantity, and description.
- Inventory Display: Display current inventory items in a table with relevant columns, designed to be clear, and filterable.
- Low Stock Alerts: Highlight items that are below a user-defined threshold, indicating that it is time to re-order.
- Generate Re-order List: Generate a text list of items that have dropped below their specified threshold. This acts as a 'tool' which may, depending on context, be used to trigger an automated re-ordering process.
- Simple CSV Import: Import inventory data from a CSV file.

## Style Guidelines:

- Primary color: Blue (#4285F4) for a sense of trust and organization.
- Background color: Light gray (#F5F5F5) to keep the focus on the data.
- Accent color: Green (#34A853) for positive actions, like adding items.
- Body and headline font: 'PT Sans' sans-serif for clarity and readability.
- Use flat, modern icons from a consistent set to represent inventory actions and categories.
- Keep a clean, tabular layout with intuitive navigation for ease of use.
- Subtle transitions and animations on data updates to provide visual feedback.
